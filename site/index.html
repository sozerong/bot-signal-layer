실유저 데이터 실험실

GitHub 공개 이벤트 일주일 치에서 봇을 걸러 낸 숫자예요. SQL로 뽑아서 엑셀이나 구글 시트로 가져갈 수 있어요.

데이터를 불러오고 있어요.

봇 필터 강도요약과 강도별 비교 표에 적용돼요. 막대는 그날 이벤트 중 남는 비율이에요.

최근 실행

    DuckDB SQL일부만 선택하고 실행하면 선택한 부분만 실행돼요
    아직 실행한 쿼리가 없어요.왼쪽에서 표 이름을 누르면 처음 100행이 나오고, 컬럼 이름을 누르면 커서 위치에 이름이 들어가요.

    자주 받는 요청을 SQL로 만들어 두었어요. 고르면 바로 실행되고, SQL을 고친 뒤 Ctrl+Enter로 다시 실행할 수 있어요.

      DuckDB SQL표와 컬럼 목록은 SQL 콘솔 탭 왼쪽에 있어요

      표를 고르면 아래 주소와 코드가 그 표에 맞게 바뀌어요. 파일 주소는 바뀌지 않아서, 시트나 노트북에서 다시 불러오면 가장 최근에 내보낸 데이터를 받아요.

      지표 하나를 네 가지 필터 강도로 나란히 봐요. 색칠한 줄이 위에서 고른 강도예요. '약하게 대비 추가'는 스스로 봇이라고 밝힌 계정을 뺀 뒤 더 빠지는 비율이고, '최소 탐지 효과'는 50:50 A/B 테스트로 잡아낼 수 있는 가장 작은 차이예요. 열 이름에 마우스를 올리면 SQL 컬럼 이름이 보여요.

      상위 값을 자르는 비율마다 미리 계산해 둔 평균과 분산으로 MDE(최소 탐지 효과)를 구해요. 봇 필터를 걸 때와 상위 값을 자를 때 MDE가 얼마나 줄어드는지 비교해 보세요.

      MDE = (1.96 + 0.84) × √(2σ² ÷ (n/2)) ÷ 평균. 양측 검정, 유의수준 5%, 검정력 80% 기준이에요. 자르기는 그날 계정당 이벤트가 기준값을 넘으면 기준값으로 낮춰요.

      이 화면의 숫자는 공개한 규칙 버전 기준이에요. 새 버전은 공개하기 전에 지표가 얼마나 바뀌는지 여기서 먼저 확인해요.

      공개한 버전

      지표별 차이

      표마다 한 행이 무엇을 뜻하는지, 몇 행인지 적었어요. 날짜별 상태는 이벤트 수와 봇 비율을 직전 7일 중앙값과 비교해서, 0.5배보다 작거나 2배보다 크면 '확인 필요'로 표시해요.

      컬럼

      날짜별 상태

      계정이나 저장소 이름을 넣으면 강도별로 빠졌는지, 어떤 근거가 어떤 규칙 버전과 점수로 걸렸는지 보여 줘요. 이름이 들어 있는 로컬 데이터에서만 보이는 탭이에요.
