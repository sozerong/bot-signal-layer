# 로컬 기준값 (이식 비교용, 지시서 K3)

C2 ~ C4의 체크포인트 "로컬과 같은 결과"는 이 문서의 값과 비교한다. 새로 잰 값이 아니라 2026-11-18 로컬 표에서 뽑은 값이다.

- **값 전체:** `docs/local_baseline.json` (silver 112개, gold 217개 값). 아래 표는 그중 사람이 볼 것만 옮겼다.
- **뽑는 스크립트:** `scripts/baseline.py`. 이식 뒤 같은 스크립트를 클라우드 쪽에 돌리고 `compare`로 대조한다. 다른 값만 찍고, 하나라도 다르면 exit 1.
- **뽑은 때의 상태:** 커밋 `91e29c6` + 지시서 K1 변경. 근거는 J1 `j1_week` 판정, truth는 K1 `k1_truth_retry` 뒤 (M-21). 같은 스크립트를 두 번 돌려 다름 0개 (silver 112개, gold 217개).

```bash
# bot-job 컨테이너 안 (로컬), 이식 뒤에는 클러스터와 BigQuery 쪽
python -m scripts.baseline all > /tmp/b.json
python -m scripts.baseline compare docs/local_baseline.json /tmp/b.json
```

- 클러스터에서는 시간과 메모리 모두 다를 것이다. 같아야 하는 것은 1절뿐이다.

## 3. 이 기준값의 한계

- **manifest 읽기는 로컬 경로뿐이다.** `scripts/baseline.py silver`가 `raw/dt=*/hour=*/_manifest.json`을 Python으로 읽는다 (Spark는 `_`로 시작하는 파일을 건너뛴다). C2에서 Bronze가 GCS로 가면 이 부분만 바꾼다.
- **Gold 연결은 DuckDB 하나다.** SQL은 BigQuery에서도 도는 꼴(`count_if` 대신 `sum(case ...)`, `{s}` 자리에 데이터셋)로 썼지만 BigQuery에서 돌려 보지 않았다 [확인 필요: C3에서].
- F-13 옛 몫이 채점 대조군 칸에 남아 있다 (M-21). 이식 비교에는 상관없다 (truth를 그대로 옮기면 같다).
