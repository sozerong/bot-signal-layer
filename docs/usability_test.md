# 분석가 사용성 시험 (데이터 실험실 화면)

이 문서는 분석가에게 화면을 직접 써 보게 하는 시험의 과제와 기록 방식이다.
사용성 시험을 진행하는 사람이 시험 전에 읽는다.

방향 문장의 "분석가가 실유저 숫자를 직접 골라 바로 가져간다"는 지금 아무도 써 보지 않은 주장이다. 사람 한 명 이상이 실제로 해 보고, 걸린 시간과 막힌 곳을 기록해서 증거로 바꾼다. 〔근거: 사용자 2026-11-22 12:49 방향성 한 문장. direction_v6.md 17회차 반박 4 "증명이 없다"〕

## 누구에게
- 분석가이거나 분석가 지망인 사람 1 ~ 3명. 팀원, 동아리 사람, 지인이면 된다. 이 프로젝트를 만든 사람(본인)은 세지 않는다. 〔근거: 판단: 만든 사람은 화면 구조를 이미 알아서 막히는 곳을 못 본다〕
- SQL을 조금 아는 사람과 엑셀만 쓰는 사람이 섞이면 더 좋다. 〔근거: docs/site_design.md 10절. 분석가는 SQL과 엑셀을 거의 모두 쓴다〕

## 준비
- 실제 데이터로 내보낸 화면(handoff_v7.md 단계 2, Q13)이 있어야 한다. 공개 전이면 로컬에서 `cd site && python -m http.server 8000`, 화면 공유로 진행해도 된다. 〔근거: handoff_v7.md 단계 2〕
- 진행자는 과제 문장만 읽어 주고 화면 사용법은 알려 주지 않는다. 질문이 오면 "화면에서 찾아보세요"로 답하고, 3분 넘게 막히면 도와주고 "도움 받음"으로 적는다. 〔근거: 판단: 사용법을 알려 주면 화면이 아니라 진행자를 시험하게 된다〕
- 녹화나 메모로 과제마다 걸린 시간, 처음 누른 곳, 막힌 곳, 한 말을 남긴다. 〔근거: 판단: 막힌 곳이 고칠 목록이 된다〕

## 과제 (신입 분석가가 실제로 받는 요청 모양)
멘토가 말한 신입 업무 "데이터 추출 요청 같은 작은 일"을 그대로 과제로 만들었다. 〔근거: 멘토: mentoring_2026-11-21.md 3절 신입 업무〕

| 번호 | 과제 (읽어 주는 문장) | 성공 기준 | 보는 것 | 근거 |
|---|---|---|---|---|
| T1 | "7월 18일에 PushEvent를 낸 실유저 계정 수를 strict 기준으로 구해서 엑셀 파일로 보내 주세요." | 숫자가 맞고 .xlsx를 받았다 | "자주 쓰는 쿼리" 카드를 찾는가, 내려받기를 찾는가 | 〔근거: site/index.html 요구사항 "특정 이벤트 종류를 낸 실유저 계정 수"〕 |
| T2 | "봇을 거르면 star 순위가 얼마나 바뀌는지 한 문장으로 말해 주세요." | star 상위 100 중 남는 개수를 말한다 | 요약을 읽고 바로 답하는가 | 〔근거: handoff_v7.md 1-5 채점된 숫자를 앞에〕 |
| T3 | "계정당 이벤트로 A/B 실험을 하려 합니다. 2% 차이를 잡으려면 계정이 몇 개 필요한가요?" | MDE 계산기의 필요 계정 수를 말한다 | 정책과 자르기를 바꿔 보는가 | 〔근거: site/index.html 실험 감도〕 |
| T4 | "이벤트 종류별로 strict 기준 봇 비율이 가장 높은 3개를 뽑아 구글 시트에 붙여 주세요." | 시트에 3행이 들어갔다 | SQL 콘솔 또는 카드, 표 복사나 IMPORTDATA | 〔근거: site/index.html SQL 콘솔, 가져가기〕 |
| T5 | "방금 받은 숫자가 언제, 어떤 규칙 기준인지 말해 주세요." | 내보낸 시각과 규칙 버전 id를 말한다 | 머리 줄이나 엑셀의 SQL 시트를 찾는가 | 〔근거: 강점 문장 "분석가 숫자는 공개한 묶음에 고정". site/index.html #about, xlsx SQL 시트〕 |

- T5가 강점 문장의 시험이다. 숫자를 받은 사람이 그 숫자의 기준을 스스로 찾지 못하면 "고정"은 사람에게 보이지 않는 것이다. 〔근거: 사용자 2026-11-22 12:49 강점 한 문장〕

## 통과 기준
- T1, T2, T4, T5를 도움 없이 과제마다 5분 안에 끝내면 통과. T3은 실험 개념을 모르는 사람이면 제외한다. 〔근거: 판단: 추출 요청 한 건이 5분을 넘으면 화면보다 슬랙으로 묻는 쪽이 빠르다. 반증 조건: 참가자가 5분이 짧다고 하면 그 말을 기록하고 기준을 다시 정한다〕
- 한 사람이라도 같은 곳에서 막히면 고칠 목록에 올린다. 〔근거: 판단: 참가자가 적어 한 번 막힌 것도 신호다〕
